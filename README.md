# OliverosTheme

## Pruebas locales sin publicar archivos

1. Mantén `Theme` en tu PC y colócalo en la carpeta de temas de BetterDiscord.
2. Crea un archivo `local.css` en la misma carpeta para tus cambios privados (este archivo está en `.gitignore`, aunque sea un archivo vacío).
3. Si usas otra ubicación, ajusta la ruta del `@import` en `Theme`.
4. Abre `index.html` (incluido en el repositorio) directamente en tu navegador si quieres previsualizar la landing localmente.
