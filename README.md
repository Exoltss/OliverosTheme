# OliverosTheme

## Pruebas locales sin publicar archivos

1. Mantén `Theme` en tu PC y colócalo en la carpeta de temas de BetterDiscord.
2. Crea un archivo `local.css` en la misma carpeta para tus cambios privados (este archivo está en `.gitignore`).
3. Abre `index.html` directamente en tu navegador si quieres previsualizar la landing localmente.
